9.1. 정규표현식#

정규표현식regular expression은 패턴 탐색 문자열이며 정규식 또는 레겍스(regex)라고 줄여서 불리기도 한다. 정규표현식은 주어진 문자열이 특정 패턴의 부분 문자열을 포함하는가를 판단할 때 활용된다.

파이썬에 정규표현식을 활용하려면 re 모듈이 유용하다.

import re

9.2. 정규표현식 함수#

정규표현식에 매칭되는 문자열을 찾거나 활용하는 다양한 함수들을 제공한다. 그중에 다음 네 개 함수가 가장 많이 사용된다.

Table 9.1 정규표현식 함수#

기능

설명

findall()

지정된 정규표현식에 매칭되는 모든 부분문자열로 구성된 리스트 반환

split()

지정된 정규표현식에 매칭되는 부분문자열로 쪼개진 문자열들의 리스트 반환

sub()

지정된 정규표현식에 매칭되는 부분문자열이 다른 지정된 문자열로 대체된 문자열 반환

search()

지정된 정규표현식에 매칭되는 최초 부분문자열의 정보를 담은 re.Match 객체 반환. 즉, 처음 찾은 부분문자열 정보만 다룸.

findall() 함수 활용 예제

아래 코드에서 사용된 r'rains?'는 rains 또는 rain 과 일치한다. s?는 s를 0번 또는 1번 사용하는 것을 의미한다.

text = "It rains a lot in rainy season"
re.findall(r'rains?', text)

['rains', 'rain']

지정된 정규표현식에 매칭되는 부분문자열이 없다면 비어 있는 리스트가 반환된다.

text = "It rains a lot in rainy season"
re.findall(r'raiins?', text)

[]

9.3. re.Match 객체#

지정된 정규표현식에 매칭되는 부분문자열에 대한 정보를 저장하는 객체며, 아래 속성과 메서드가 많이 활용된다.

Table 9.2 re.Match 객체 속성과 메서드#

속성/메서드

설명

string

탐색 대상이 되는 문자열 원본을 저장하는 속성

span()

지정된 정규표현식에 매칭되는 부분문자열의 시작 인덱스와 끝 인덱스로 구성된 튜플을 반환하는 메서드. 단. 끝 인덱스는 실제 끝 인덱스보다 1 큰값으로 지정됨.

start()

지정된 정규표현식에 매칭되는 부분문자열의 시작 인덱스를 반환하는 메서드.

end()

지정된 정규표현식에 매칭되는 부분문자열의 끝 인덱스를 반환하는 메서드. 단. 끝 인덱스는 실제 끝 인덱스보다 1 큰값으로 지정됨.

group()

지정된 정류표현식과 일치하는 부분문자열을 반환하는 메서드.

text = "It rains a lot in rainy season"
match = re.search(r'raiins?', text)

깃발 옵션

  • re.IGNORECASE makes the pattern case insensitive so that it matches strings of different capitalizations

  • re.MULTILINE is necessary if your input string has newline characters (\n), this flag allows the start and end metacharacter (^ and $ respectively) to match at the beginning and end of each line instead of at the beginning and end of the whole input string.

  • re.DOTALL allows the dot (.) metacharacter match all characters, including the newline character (\n)

It is recommended that you compile them if you need to be testing or extracting information from many input strings using the same expression. This method returns a re.RegexObject

The returned object has exactly the same methods as above, except that they take the input string and no longer require the pattern or flags for each call..

result = regex.search("Hello World is the easiest")
